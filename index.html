    Sem chave o app já funciona. Uma chave gratuita acelera a busca (de 3 para 10 consultas/s). Gere em conta NCBI → API Key. Fica salva apenas neste navegador.

    Fonte: PubMed via NCBI E-utilities. Cada periódico é consultado por sua abreviação NLM (campo [ta]); os artigos são ordenados por data e classificados em dois níveis a partir do título: subespecialidade (1º nível) e grupo de transtornos (2º nível). Selecione uma subespecialidade para navegar pelos grupos de transtornos; um mesmo artigo pode receber 2–3 rótulos quando o tema é transversal (ex.: ideação suicida na depressão; TDAH e transtorno de conduta na infância; cetamina em depressão resistente e neuroestimulação).
    Aplicativo estático: todo o processamento ocorre no navegador. Para hospedar, basta publicar este index.html no GitHub Pages. A classificação por subespecialidade é heurística e serve para triagem rápida, não substitui a leitura do artigo.
    Instalar no celular: Android/Chrome mostra o botão Instalar app acima. No iPhone, abra no Safari e use Compartilhar → Adicionar à Tela de Início.
